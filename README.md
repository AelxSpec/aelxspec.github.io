# ВПИ · Штабная карта

Однофайловое веб-приложение для ГМа и игроков ролевых военно-политических игр: провинции и границы государств, города, соединения со штатами и оснащением, аэродромы и узлы снабжения, месторождения, железные и обычные дороги, штриховые зоны, стрелки, театры военных действий с автоматической линией фронта, панель страны, снимок карты в полном разрешении и персональные сборки для игроков.

## Как запустить

1. Открыть `vpi_map_v3_0.html` в Chrome или Edge (двойным кликом или через локальный сервер: `python -m http.server 8000`).
2. «Новая партия (ГМ)» → выбрать файл карты → Настройки: государства и игроки.
3. «Сохранить» — мастер-файл партии; «Сборка игроку» — персональный файл без скрытого.

Игроку отправляется: этот HTML + его сборка + файлы карт.
