# ВПИ · Штабная карта

Инструмент для ведения ролевых военно-политических игр (ВПИ): ГМ рисует на подложке-карте провинции, города, войска, дороги, театры военных действий и выдаёт игрокам персональные сборки со срезанным скрытым.

## Устройство

- Всё приложение — один файл `vpi_map_v3_0.html` (HTML + CSS + vanilla JS, без сборки и зависимостей). Так и должно оставаться: игроку отправляют этот HTML + json-сборку + файлы карт.
- Интерфейс и комментарии в коде — на русском. Стиль кода плотный, однострочные функции, короткие имена — держаться его.
- Данные партии — объект `data` (см. `newData()`), сохраняется в JSON. Файлы карт в сохранение не входят, подключаются при запуске.
- Любое изменение формата данных обязано проходить через `migrate(d)`: старые сохранения должны открываться без потерь.
- Видимость: `vis` = `"all" | "gm" | "owner" | [playerId…]`, проверка `canSee()` в UI и `filterForPlayer()` при выгрузке сборки. Секретность обеспечивает только сборка — при добавлении новых сущностей их надо фильтровать и там.
- Отрисовка: два SVG-слоя — `#overlay` (база, `drawBase()`) и `#overlay2` (оверлей, `drawOverlay()`); планировщик `render()` / `renderOverlayOnly()`. Кэши: `bumpBorders()` для границ, `bumpWar()` для фронтов.
- Правки данных: перед изменением `snapshot()` (undo), после — `markDirty()`.
- Экономика (v3.1): `data.econ` = `{year, recipes, nat:{[nid]:{cap,mods,need,adds}}, log}`; в провинции `stats.mines` (добывающие точки) и `stats.fabs` (предприятия). Расчёт — `econCalc(nid)`, столица пула — `econCap(nid)`, запасы — `stockGet/stockSet` (оружие и техника лежат в `data.stocks.eq`, прочее в `data.stocks.res`). Цепочки заводов по умолчанию — `DEF_RECIPES` (заготовка, ГМ правит в «Механике заводов»).
- Всплывающие подсказки: любой `title` автоматически превращается в маленькое окошко (`#tip`); `data-tipres="nid|res"` — справка по ресурсу.

## Запуск

Открыть файл в Chromium-браузере напрямую или через локальный сервер (`.claude/launch.json`, конфигурация `vpi-map`):

```
python -m http.server 8000 --bind 127.0.0.1
```

→ http://127.0.0.1:8000/vpi_map_v3_0.html. File System Access API (запись «на место», Ctrl+S) работает в Chrome/Edge.
